## Автоматические тесты (JUnit)

Запуск: Android Studio → правый клик по папке `app/src/test` → Run Tests, либо `./gradlew test`.

- `StudentValidatorTest` — 6 тестов: корректные данные, пустые поля, пробелы, дубликаты, нормализация
- `DateToolsTest` — 4 теста: корректная дата, неверный формат, несуществующая дата, сегодняшняя дата
- `StatsCalculatorTest` — 2 теста: пустой список, подсчёт каждого статуса
- `RecordFilterTest` — 5 тестов: без фильтров, по группе, по студенту, по датам, без совпадений
