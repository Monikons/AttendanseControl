# AttendanceControl — Система контроля посещаемости студентов

Мобильное Android-приложение на Kotlin для преподавателя или куратора группы: учёт посещаемости студентов колледжа (присутствовал / отсутствовал / опоздал), история отметок и простая статистика. Приложение работает локально на одном устройстве.

**Состояние:** спринт 5 из 6 — Статистика, фильтрация и надёжность.

## Технологии

- Kotlin, Android Studio, Android SDK (minSdk 24, compileSdk 34)
- XML-разметка, Activity, RecyclerView (View-based интерфейс)
- Room (SQLite) — локальное хранение данных
- JUnit — модульные тесты
- Git — контроль версий; Markdown — документация

## Требования

- Android Studio с поддержкой AGP 8.9 (Gradle 8.11, JDK 17 или 21)
- Эмулятор или устройство с Android 7.0 (API 24) и выше

## Открытие и запуск

1. Клонировать репозиторий или распаковать архив проекта.
2. В Android Studio выбрать **File → Open** и указать папку `AttendanceControl`.
3. Дождаться синхронизации Gradle (при необходимости Android Studio создаст `gradle-wrapper.jar` и `local.properties`).
4. Выбрать эмулятор/устройство и нажать **Run ▶**.
5. Тесты: **Run Tests** для папки `app/src/test` или `./gradlew test`.

## Экраны

- **Главный экран** — название приложения и кнопки перехода к разделам.
- **Студенты** — добавление студента (фамилия, имя, группа), список, удаление с подтверждением.
- **Отметить посещаемость** — выбор группы, даты и дисциплины; статус каждого студента.
- **Статистика** — история отметок, фильтры по группе, студенту и датам, сводка по статусам.

## Возможности

- Главный экран со сводкой: число студентов и отметок.
- Форма добавления студента с подсказками об ошибках под полями; поиск по фамилии, имени и группе.
- Быстрая отметка: кнопка «Все присутствуют»; ранее сохранённые отметки занятия подставляются автоматически.
- История отметок с фильтрами, процент посещаемости, цветовая индикация статусов.

## База данных Room

| Таблица | Поля | Назначение |
| --- | --- | --- |
| `students` | id, firstName, lastName, groupName | Студенты |
| `attendance` | id, studentId (FK → students, CASCADE), lessonDate, subject, status, comment | Отметка студента на занятии |

Уникальный индекс `(studentId, lessonDate, subject)` обеспечивает одну итоговую отметку на студента и занятие. Отдельная сущность Lesson не вводится: занятие описывается датой и дисциплиной в записи `attendance`. Даты хранятся строкой `ГГГГ-ММ-ДД`.

## Ограничения

- Локальное использование на одном устройстве, без синхронизации и авторизации.
- Хранятся только вымышленные данные студентов (персональные данные в репозиторий не добавляются).
- Дата занятия вводится вручную в формате ГГГГ-ММ-ДД.
